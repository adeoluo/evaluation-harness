# Data Card - Evaluation Harness

The framework bundles two small datasets so that results are reproducible with no network
access. Both are synthetic and created for this project; neither contains personal data.

## arithmetic (generated)

- **Provenance:** generated deterministically at runtime from a seed; nothing is stored
  on disk or downloaded.
- **Composition:** two-operand integer problems using `+`, `-`, `*`, with operands in
  `[2, 99]`. Default size 60.
- **Licensing:** generated by this repository; MIT, same as the code.
- **Contamination:** not applicable - problems are produced on demand and are not drawn
  from any external corpus.

## sentiment (`src/evaluation_harness/tasks/data/sentiment.jsonl`)

- **Provenance:** hand-authored for this project. Each record is a short, synthetic
  movie-review-style sentence with a `positive` or `negative` label.
- **Composition:** 48 examples, balanced across labels, including negation and
  mixed-polarity sentences intended to probe lexicon-classifier failure modes.
- **Format:** JSON Lines, fields `text` and `label`.
- **Licensing:** authored by this repository; MIT.
- **Preprocessing:** none; sentences are used verbatim.
- **Known biases and gaps:** short, single-sentence, English, movie-domain text with
  clear sentiment words; it is a demonstration set, not a representative sample of
  real-world reviews.
- **Contamination:** the sentences are original to this repository. Users bringing their
  own tasks should run the contamination scan against their training corpus.

## Ethical considerations

Both datasets are synthetic and contain no personal, sensitive, or copyrighted content.
